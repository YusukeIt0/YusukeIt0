**Startup Operator**

I help startups build their businesses and teams, and connect with the people they need.

## How I think

AI is a tool. People are responsible for the experience.

| I focus on | I ask |
| :--- | :--- |
| **Purpose** | What will people find valuable about the experience? |
| **Scope** | What should I build or leave out? Could something that already exists do the job? |
| **Quality** | How will each change affect the overall experience? |

## On GitHub

I build and experiment with AI, starting from things I need or want to try. This is where I turn ideas into working prototypes and learn by using them.
